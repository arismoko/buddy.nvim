                                                                    *buddy*
*buddy.txt*  MCP server for Neovim

buddy is an MCP (Model Context Protocol) server for Neovim.
It enables AI assistants to interact with your editor through tools.

For tool reference, see |buddy-tools|.

Quick start: >lua
  require("buddy").setup({
    auto_start = true,
    port = 7234,
  })
<

------------------------------------------------------------------------------
                                                                     *buddy.setup()*
                               `buddy.setup`({opts})
Setup buddy with the given options

Parameters ~
{opts} `(table|nil)` Configuration options
Fields ~
{host} `(string)` Server host (default: "127.0.0.1")
{port} `(number)` Server port (default: 7234)
{auto_start} `(boolean)` Start server automatically (default: false)
{debug} `(boolean)` Enable debug logging (default: false)
{tools_dir} `(string|nil)` Custom tools directory
{tools} `(table)` Per-tool configuration

Usage ~
`require("buddy").setup({ auto_start = true })`
